Fit the intercept-only model

Task: predict the intercept

Before running any code, write down your prediction. You have computed the mean of these differences before. What value do you expect the intercept to be?

lsmodel1 <- lm(difference ~ 1, data = darwin_diff)

The formula difference ~ 1 means “fit an intercept only.” The intercept is the mean of the paired differences. The coefficient table tests whether that mean differs from zero — the same question the permutation test in Session 3 answered.

Read the coefficient table

Task: read the summary output

Run the code below. Compare the intercept with your prediction, then answer:

  1. What does the estimate represent?
  2. What does the t-value represent, and how does it relate to the ranking exercise from hour 1?
  3. Is there evidence that the mean difference is not zero?
  1. The estimate is the mean of the fifteen paired differences — the average advantage of cross-pollination over self-pollination within a pot.
  2. The t-value is the estimate divided by its standard error. A larger absolute t-value means the estimate is further from zero in standard-error units, just as in the ranking exercise.
  3. Check the p-value. If it is below 0.05, there is evidence that the mean difference is not zero, consistent with the permutation test from Session 3.

Compare with the one-sample t-test

Task: confirm the equivalence

Run the code below. Compare the p-value from t.test() with the p-value from summary(lsmodel1). They should be identical.

This confirms that the intercept-only linear model on paired differences is the same test as a one-sample t-test. The linear model is the more general framework.

Composition task: fit the unpaired model

Task: write an lm() call for the unpaired comparison

You have just fitted a model that respects the paired design:

lsmodel1 <- lm(difference ~ 1, data = darwin_diff)

Now write an lm() call that ignores the pairing entirely: model height as a function of pollination type, using the original darwin data frame. Assign the result to lsmodel2 and run summary() on it.

The response is height, the predictor is type, and the data are darwin. The formula takes the form response ~ predictor.

lsmodel2 <- lm(height ~ type, data = darwin)
summary(lsmodel2)

Task: compare the two models

Look at the coefficient table for lsmodel2.

What does the typeSelf coefficient estimate? Is this the same quantity as the intercept of lsmodel1?

The typeSelf coefficient estimates the difference in mean height between self-pollinated and cross-pollinated plants — the same quantity as the intercept of lsmodel1, but with the opposite sign (Self minus Cross rather than Cross minus Self). The absolute value is the same.

NoteWhy pairing matters

Darwin paired his plants by parent because genetic lineage might play a large role in natural variance in height. By computing the difference within each pair, the paired analysis minimises this source of variation and isolates the effect of pollination type. The unpaired analysis ignores this structure. The lesson: a model should respect the design that generated the data.
